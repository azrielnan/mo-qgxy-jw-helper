# 华北理工大学轻工学院教务系统助手

适配华北理工大学轻工学院综合教务系统的用户脚本，面向 ScriptCat / Tampermonkey 使用。

本仓库只包含主功能脚本：

```text
华北理工大学轻工学院教务系统助手.user.js
```

## 功能

- 快捷评教
- 自动登录选项恢复
- 均分绩点计算器
- 培养方案查询
- 本学期成绩查询
- 分项成绩查询
- 成绩更新提醒
- 教材选择一键全选 / 全不选
- 关于、反馈、更新日志、赞赏页面
- 主脚本内置「界面美化」开关

## 适配站点

```text
https://jws.qgxy.cn/*
```

## 安装方式

1. 安装 ScriptCat 或 Tampermonkey。
2. 新建用户脚本。
3. 复制 `华北理工大学轻工学院教务系统助手.user.js` 内容并保存。
4. 打开华北理工大学轻工学院综合教务系统。

## 与高级美化脚本联动

如果你同时安装另一个仓库中的高级美化脚本：

```text
华北理工大学轻工学院教务系统高级美化.user.js
```

那么本脚本里的「界面美化」开关会控制高级美化脚本是否启用。
